# LINE vs อีเมล — ใช้อย่างไรดี?

## แนะนำ: ใช้ LINE เป็นหลัก

เหมาะกับครอบครัวไทย — เปิดบ่อย แชร์ในกลุ่มได้ทันที **ไม่ต้องตั้งค่าใดๆ**

1. กด **💬 รายงาน**
2. กด **แชร์เข้า LINE**
3. เลือกแชท (แม่, พ่อ, กลุ่มบ้าน ฯลฯ) → ส่ง

บนมือถือมักเลือก LINE จากเมนูแชร์ได้เลย

## อีเมล — ทางเลือก

ใช้เมื่ออยากเก็บเป็นหลักฐานในกล่องจดหมาย — ต้องตั้ง Web3Forms Access Key ครั้งเดียว (ฟรี)

## ทำไมไม่ส่งเข้า LINE อัตโนมัติ 100%?

LINE Notify ปิดบริการแล้ว — การส่งเข้าแชทโดยไม่กดส่งเอง ต้องใช้ LINE Official Account + เซิร์ฟเวอร์ (ซับซ้อนและมีค่าใช้จ่าย)

วิธี **แชร์เข้า LINE** ที่ใช้อยู่: ฟรี ใช้ได้ยาวๆ ไม่หมดอายุ เหมาะครอบครัว
