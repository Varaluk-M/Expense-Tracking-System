# ส่งรายงานทางอีเมล

## วิธีที่ 1 — เปิดแอปอีเมล (ใช้ได้ทันที ไม่ต้องตั้งค่า)

1. เลือกช่วงเวลา (รายวัน / เดือน / ปี)
2. กดปุ่ม **📧 รายงาน**
3. ใส่อีเมลผู้รับ → กด **เปิดแอปอีเมล**
4. โปรแกรมอีเมล (Gmail, Outlook ฯลฯ) จะเปิดพร้อมข้อความรายงาน — กดส่ง

## วิธีที่ 2 — ส่งตรงจากเว็บ (EmailJS)

1. สมัครฟรีที่ https://www.emailjs.com/
2. สร้าง **Email Service** (เช่น Gmail)
3. สร้าง **Email Template** ใส่ตัวแปร:
   - `{{to_email}}` — ผู้รับ
   - `{{subject}}` — หัวข้อ
   - `{{message}}` — เนื้อหารายงาน
   - `{{from_name}}` — ชื่อผู้ส่ง
4. คัดลอก `js/email-config.example.js` → `js/email-config.js` ใส่ key จริง
5. Push ขึ้น GitHub — จะเห็นปุ่ม **ส่งทันที (EmailJS)**
