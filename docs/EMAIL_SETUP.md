# ส่งรายงานเข้าอีเมลโดยตรง (ไม่เปิดแอปอีเมล)

ใช้บริการ **Web3Forms** (ฟรี) ส่งรายงานจากเว็บเข้ากล่องจดหมายของคุณทันที

## ตั้งค่าครั้งเดียว (ประมาณ 2 นาที)

1. เปิด https://web3forms.com/
2. ใส่ **อีเมลที่ต้องการรับรายงาน** (เช่น Gmail ของคุณ)
3. กดรับ **Access Key** ทางอีเมล (หรือแสดงบนหน้าเว็บ)
4. ในแอป → **⚙️ ตั้งค่า** → วาง Access Key ในช่อง **Web3Forms Access Key**
5. กด **บันทึก**

## วิธีส่งรายงาน

1. เลือกช่วง **รายวัน / เดือน / ปี**
2. กด **📧 รายงาน**
3. กด **ส่งเข้าอีเมลของฉัน**
4. ตรวจสอบกล่องจดหมาย (หรือโฟลเดอร์ **สแปม**)

## หมายเหตุ

- รายงานส่งไปที่อีเมลที่ลงทะเบียนกับ Web3Forms ตอนสร้าง Key
- Access Key เก็บในบัญชีของคุณ (แยกตามผู้ใช้ที่ login)
- ฟรีประมาณ 250 ฉบับ/เดือน (เพียงพอสำหรับครอบครัว)
